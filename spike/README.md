# Spike: сравнение GUI-фреймворков (Gio vs Wails, Fyne — отложен)

Цель этапа 0 (§13.7, идеи.md §8): одинаковую маска заданий на разных фреймворках,
сравнить «на ощупь» и «на код».

## Маска заданий (у каждого спайка)

- Канва на всё окно, сетка 32 (мир 2000×1500, мир/экран 1:1 при zoom=1).
- 3 блока 120×64: drag&drop, перемещение мышью, snap к сетке на отпускании.
- Коннектор A→B (правый-центр A → левый-центр B, колено по x-середине),
  **живая перерисовка** маршрута при переносе блока.
- Pan: тянуть пустое место (primary-drag).
- Zoom: колесо к курсору, 10%–800% (поведение «земля под курсором»).
- HUD: zoom% + pan.

## Как запускать

```powershell
# Gio (без cgo, чистый go build)
cd spike/gio;  go build -o spike-gio.exe .;  .\spike-gio.exe

# Wails (ОСОБЕННОСТЬ: обязательно -tags desktop,production — иначе окно
# «молча» выходит с кодом 0)
cd spike/wails; go build -tags desktop,production -o spike-wails.exe .; .\spike-wails.exe
```

Fyne: **отложен** — требует cgo + MinGW (на этой машине CGO_ENABLED=0, компилятора C нет).
Если появится тулчейн: `cd spike/fyne; go build -o spike-fyne.exe .` (код спайка лежит).

## Чеклист сравнения (заполняется по замерам обеих спайков)

1. Гладкость zoom колесом к курсору (10% и 800%).
2. Drag блока на zoom 800% — дрожит/уходит контроль/перерисовка?
3. Отзывчивость: заметны ли задежки/лаг при 50+ объектах?
4. Текст при малых/больших zoom — чёткость, масштабируется ли норм.
5. DPI и HiDPI по умолчанию.
6. Сколько усилия ушло на: окно, обработку ввода, рисование примитивов:
   запомнить «необычно больные» места (см. прим. ниже).
7. Размер бинаря, зависимости.

## Найденные грабли (заполняется)

- **Wails:** `go build` без `-tags desktop,production` тихо выходит (exit 0, без окна).
  Требует webview2 runtime (на Windows 10/11 обычно есть), на Linux/mac — webkit2gtk + cgo.
- **Gio:** new input API (gio ≥ v0.10): `event.Op(ops, tag)` в кадре +
  `q.Event(pointer.Filter{Target: tag, Kinds: ...})` из `app.FrameEvent.Source`,
  захват через `q.Execute(pointer.GrabCmd{Tag:, ID:})`. Весь ввод — один тег на окно
  + ручной hit-test (самый надёжный вариант для редактора).
- **Fyne:** блокирует build при отсутствии C-компилятора (OpenGL bindings на cgo);
  кастомные widgets + ручной Layout — рабочий путь, но требует тестов
  (passed identity: см. spike/fyne/main.go — было скелетно).
