## ADR-0000 — Инструментальная площадка спайков (2026-11-01 / 2026-11-04)

**Вопрос:** как быстро и честно сравнить GUI-фреймворки для редактора схем.

**Решение:** три независимых модуля-спайка (`spike/{gio,fyne,wails}`) с
идентичной маской заданий (сетка + 3 блока + коннектор с live-перерисовкой +
pan + zoom к курсору). Главный репо-модуль остаётся без зависимостей от GUI.

**Альтернативы:** один общий go.mod (было бы сложнее отключать выбранный
фреймворк); spike одного фреймворка (неустойчиво к невидимым осям).

## ADR-0001 — Выбор UI-фреймворка (ОТКРЫТО, 2026-11-04)

**Вопрос:** Gio / Fyne / Wails — на чём строить редактор этапа 1.

**Статус 2026-11-04:**
- ✅ **Gio** собрался без cgo (`go build`), вход через event API v0.10 — окно живое.
- ✅ **Wails** собрался без cgo **с `-tags desktop,production`** (иначе тихий exit 0);
   окно живое; вся интерактивность в HTML/JS, мост Go↔JS не нужен (клиентская маска).
- ❌ **Fyne отклонён (на текущем железе)** — native-сборка требует cgo+MinGW,
   а на машине CGO_ENABLED=0 и нет компилятора C. Код спайка лежит в `spike/fyne`,
   вернуться если появится тулчейн.

**Дальше:** гонять спайки по чеклисту `spike/README.md` → выбрать.

**Альтернативы:** Gio (всё Go, контроль рендера) vs Wails (максимальная скорость
UI, webfrontend). Решение — после запуска спайков владельцем.

## ADR-0002 — Кроссплатформенность сразу (2026-11-04)

**Вопрос:** Windows-only или кроссплатформенность с первого этапа.

**Решение:** целиться в кроссплатформность сразу (владелец подтвердил), но без
дорогих накладных: CI (windows+linux+macos) на основном модуле late; GUI-путь
выбираем с учётом кроссплатформенности (Gio — кросс без cgo; Wails — кросс,
но на Linux/mac требует webkit2gtk/cgo).

**Альтернативы:** Windows-only (Walk-类 путь) — отклонено владельцем.

## ADR-0003 — Двухэтапность (2026-11-04)

**Вопрос:** физика/матмодели сразу или после редактора.

**Решение:** этап 1 — чистый графический редактор (блоки, коннекторы, пересечения,
порядок, undo/redo, save/load); этап 2+ — типизация блоков, netlist, DC/transient/AC.
Деталь: `simulate` не scaffoldить на этапе 1; блоки этапа 1 без физического
типа (только иконка + подпись). Полный контекст — §1/§8/§10 идеи.md.

**Альтернативы:** сразу с симуляцией (отклонено: растворяет MVP, тормозит выкатку
работающего редактора).
